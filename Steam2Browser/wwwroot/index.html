Download blobs by depot range

A blob is a depot's metadata: the file list of one version, tens to a few hundred kilobytes depending on how many files that version had. Pulling a span of them fills in version history, per-version diffs and the global file search for every depot in the range, for a small fraction of what the dats would cost.
